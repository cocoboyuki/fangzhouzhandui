# 2026 CRTC 参赛机器人设计与实现历程

**队伍名称：方舟战队**

## 三、电机运动（单一/全部）

### 功能描述与开发历程

电机运动模块主要验证单个电机的转动控制，以及多个电机协同工作时的方向和速度一致性。相比只验证电机是否能够转动，我们更关注控制指令、编码器反馈与机器人实际运动之间是否对应。

### 具体调试方法

- **单电机测试：**先逐个检查电机能否正常启动和停止，再确认正反转方向、编码器反馈和速度参数是否正确。单路测试完成后再进行多电机联调，避免多个问题同时出现时难以定位原因。
- **四轮方向校准：**将机器人架空，逐一发送低速指令，观察四个轮子的转向和编码器计数变化。随后将机器人放在地面上进行低速直线测试，检查是否存在明显跑偏。若某个轮子的方向不正确，优先检查接线和方向配置，而不是直接修改上层运动逻辑。
- **速度标定：**在平整地面上设置固定速度和运行时间，测量机器人实际移动距离，并与指令对应的理论距离比较。若偏差较大，需要依次检查轮径、编码器计数定义、减速比和驱动板参数。测量时应尽量保持电池电量和地面条件一致，减少外部因素造成的误差。
- **速度限制：**调试阶段先使用较低的速度上限，确认电机方向和停止逻辑正常后，再逐步提高速度。目前程序中的目标速度上限暂按 300 mm/s 进行低速测试，后续再根据实际场地和制动表现调整。

在多电机控制中，单个电机正常并不代表整车运动一定准确。四轮之间的速度差、轮胎与地面的摩擦差异，以及底盘装配误差，都可能造成实际轨迹偏离预期。因此，后续还需要对直行距离、横移距离和旋转角度进行重复测试，并根据测试结果修正参数。
